# CS:APP 1장 퀴즈 정답 및 해설

## 선택형

### Q1. 비트와 컴파일 과정

정답: **2, 3, 5**

- 1은 틀렸습니다. 텍스트 파일과 바이너리 파일을 포함한 모든 시스템 정보는 비트의 묶음입니다. 텍스트 파일은 그 바이트를 문자 인코딩에 따라 해석하는 파일입니다.
- 2는 맞습니다. 비트열의 의미는 비트 자체가 아니라 그것을 해석하는 문맥에 따라 결정됩니다.
- 3은 맞습니다. 전처리기, 컴파일러, 어셈블러, 링커 순서로 처리됩니다.
- 4는 틀렸습니다. 어셈블러는 어셈블리 코드를 재배치 가능 목적 파일로 번역합니다. 여러 목적 파일을 결합하고 외부 심볼을 해결하는 일은 링커가 담당합니다.
- 5는 맞습니다. 링커는 심볼 해석과 재배치를 거쳐 실행 가능한 목적 파일을 만듭니다.

핵심 개념: bits + context, 컴파일 시스템, 링커의 역할.

### Q2. `hello` 프로그램의 실행

- A: **주기억장치(main memory)**
- B: **프로그램 카운터(PC)**

해설: 셸은 사용자 명령을 읽는 응용 프로그램입니다. 운영체제의 도움으로 디스크에 있는 실행 파일의 코드와 데이터가 주기억장치에 적재되고, CPU는 PC가 가리키는 주소의 명령을 가져와 실행합니다. PC는 실행 중 다음 명령을 가리키도록 계속 갱신됩니다.

핵심 개념: 셸, 주기억장치, CPU, PC.

### Q3. 캐시와 메모리 계층

정답: **1**

```text
레지스터 → L1 캐시 → L2 캐시 → L3 캐시 → 주기억장치 → 디스크
```

해설: 계층의 위쪽으로 갈수록 일반적으로 더 작고 빠르며 byte당 비쌉니다. 아래쪽으로 갈수록 더 크고 느리며 byte당 저렴합니다. 상위 계층은 하위 계층 데이터의 일부를 캐시합니다.

핵심 개념: 메모리 계층의 순서와 특성.

### Q4. 운영체제의 추상화

1. **가상메모리**
2. **파일**
3. **프로세스**
4. **스레드**

해설:

- 가상메모리는 별도의 물리 메모리가 아니라 프로세스마다 균일하고 사적인 주소 공간을 제공하는 추상화입니다.
- 파일은 서로 다른 I/O 장치를 바이트의 연속으로 추상화하여 공통된 읽기·쓰기 방식으로 다루게 합니다.
- 프로세스는 실행 중인 프로그램에 대한 추상화이며, 프로그램이 CPU와 메모리를 독점하는 것 같은 환상을 제공합니다.
- 한 프로세스의 스레드들은 같은 코드와 전역 데이터를 공유하지만 각자 제어 흐름을 가집니다.

핵심 개념: 프로세스, 스레드, 가상메모리, 파일.

## 서술형

### Q1. 문맥 전환

예시 답안:

> 운영체제가 현재 프로세스의 PC와 레지스터 같은 실행 문맥을 저장하고, 다음 프로세스의 문맥을 복원한 뒤 그 프로세스에 제어를 넘기는 과정이다.

채점 핵심:

- 현재 프로세스의 문맥을 **저장**한다.
- 다음 프로세스의 문맥을 **복원**한다.
- 실행 제어가 다음 프로세스로 넘어간다.

### Q2. 캐시와 지역성

시간 지역성을 사용한 예시 답안:

> 최근 사용한 데이터를 가까운 미래에 다시 사용할 가능성이 높으므로, 그 데이터를 빠른 캐시에 보관하면 느린 하위 저장장치에 접근하는 횟수를 줄일 수 있다.

공간 지역성을 사용한 예시 답안:

> 방금 접근한 주소 주변의 데이터에도 곧 접근할 가능성이 높으므로, 인접 데이터를 캐시에 함께 가져오면 많은 접근을 빠르게 처리할 수 있다.

둘 중 한 가지 지역성을 정확하게 설명하면 됩니다.

### Q3. 병렬성과 Amdahl의 법칙

#### 3.1 개선 후 실행 시간

개선되는 부분은 `10초 × 0.8 = 8초`, 개선되지 않는 부분은 `10초 × 0.2 = 2초`입니다.

```text
T_new = 2초 + 8초 / 4
      = 4초
```

정답: **4초**

#### 3.2 전체 가속비

```text
speedup = 기존 실행 시간 / 개선 후 실행 시간
        = 10 / 4
        = 2.5
```

정답: **2.5배**

#### 3.3 동시성과 병렬성

정답: **병렬성**

해설: 동시성은 여러 활동이 진행 중인 일반적인 상태이고, 병렬성은 동시 실행을 이용하여 실제 성능을 높이는 것입니다. 여러 코어가 동시에 작업하여 실행 시간을 줄였으므로 병렬성에 해당합니다.

핵심 개념: Amdahl의 법칙, 동시성과 병렬성.
